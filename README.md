# 🎓 Student Management System

A console-based C++ application for managing student records using Object-Oriented Programming principles.

## 📋 Features

- ✅ Add new student records
- ✅ Display all students
- ✅ Search student by roll number
- ✅ Update student details
- ✅ Delete student records
- ✅ Automatic grade calculation (A, B, C, D, F)
- ✅ File-based data persistence
- ✅ Input validation

## 🛠️ Technologies Used

- **Language:** C++
- **Concepts:** OOP (Classes, Encapsulation, Abstraction)
- **Data Structure:** Arrays
- **File Handling:** fstream (Text files)

## 🎯 OOP Concepts Demonstrated

1. **Encapsulation:** Private data members with public getter methods
2. **Abstraction:** Complex grade calculation hidden in methods
3. **Classes & Objects:** Student class with multiple objects
